## Assignment Summaries

### 1. java_at1 — Assignment 1 (CO1)
Covers fundamental Java programming, Object-Oriented Programming (OOP) concepts, class design, encapsulation, inheritance, polymorphism, abstract classes, interfaces, and package structures.

### 2. java_at2 — Assignment 2 (CO2)
Covers Strings/StringBuilder/StringBuffer under load, the Java Collections Framework (ArrayList, LinkedList, ArrayDeque, HashMap, TreeMap, LinkedHashMap), the `hashCode`-`equals` contract, Generics, Comparators, and Hospital Emergency Triage queues.

### 3. java_at3 — Assignment 3 (CO3)
Covers robust Exception Handling (custom exceptions, chaining, try-with-resources) and Multithreading (thread lifecycle, synchronization, race conditions, deadlock prevention, producer-consumer with `wait()`/`notifyAll()`, and concurrent processing with `ExecutorService`, `Callable`, and `Future`).

### 4. java_at4 — Assignment 4 (CO4)
Covers GUI development using AWT and Swing (layouts, event-driven programming, canvas painting, look-and-feel customization) and database persistence with JDBC.

### 5. java_at5 — Assignment 5 (CO5)
Covers enterprise persistence, file I/O streams, object serialization, adversarial security validation, transactional batch loaders, and storage migration architecture.
